# T7 Golden Reference — get_profile 外部访问分析

## 任务

不修改任何代码，分析 `get_profile` 函数直接和间接触发的所有外部资源访问。

## 标准答案

### get_profile 触发的外部访问（共 2 项）

#### 访问 1：系统时钟（Clock）

- **资源类型**：系统时钟 / 当前时间
- **调用链**：`get_profile` → `cache.kv::get()` → `time.clock::now()`
- **边界模块**：`time.clock`（`now()` 是唯一读取系统时钟的函数）
- **触发条件**：无条件触发（每次调用 `get_profile` 都会经过 `cache.kv::get()`）

#### 访问 2：数据库读（Database Read）

- **资源类型**：持久化存储 / 数据库
- **调用链**：`get_profile` → `user.store::load_profile()`
- **边界模块**：`user.store`（`load_profile` 是访问数据库的直接接口）
- **触发条件**：仅在 cache miss 路径上触发（cache 命中时不读数据库）

### update_profile 独有的外部访问（不属于 get_profile）

- **数据库写（Database Write）**：`update_profile` → `user.store::save_profile()`
  - `get_profile` 只读不写，不触发数据库写入
